    Path 1: Design your LaTeX package step by step¶

    In this exercise, we build an APM package, similar to latex-skills. The goal is to separate the LaTeX workflow into clear specialist skills and an orchestrator that keeps the primary conversation session compact.

    By the end of the chapter, you will understand how a LaTeX package routes figure and table edits, Mermaid exports, prose polishing, and PDF compilation without pooling all rules into a single monolithic skill.

    Motivation: why an agentic LaTeX workflow?¶

    • Repetitive toil: Academic writing repeatedly cycles through table formatting, figure insertion, citation checks, and compilation failures.
    • Standardized conventions: Conference templates are consistent enough to encode as reusable execution rules.

    Architecture overview and theory cross-references¶

    A brittle package mixes routing, editing rules, and compiler output in one prompt. In this exercise, our package separates those concerns into a orchestrator and specialist skills, implementing the separation of concerns discussed in the package organization guide.

    Architectural design patterns used¶

    Before authoring primitives, review how the package maps to the patterns and anti-patterns defined in the architectural design patterns guide:

    Pattern name Where used? Why used?
    R1. SPLIT Package architecture across latex-skills Decomposes a monolithic prompt into independent specialist skills and an orchestrator.
    S3. ORCHESTRATOR FACADE latex-workflow Exposes a single entrypoint while coordinating multi-step execution behind the scenes.
    B2. CONDITIONAL DISPATCH latex-workflow dispatch table Classifies intent to load only the relevant skill instead of loading all rules at once.
    C3. THREAD SPAWN compile-pdf Runs noisy compilation in an isolated child thread that returns only a compact receipt.
    C1. LAZY ASSET latex-table-formatter and latex-figure-formatter Stores LaTeX templates in external asset files, loading them into context only on demand.
    S7. DETERMINISTIC TOOL BRIDGE latex-compiler Bridges agent intent to deterministic CLI commands (latexmk, lualatex)
    S4. VALIDATION DECORATOR latex-compiler receipt verification Enforces deterministic pass/fail gates and concise error digests before returning to the parent.
    C2. PERSONA PRELOAD citations-expert, latex-code-expert, and latex-compiler Scopes execution roles with specialized instructions and restricted toolsets for each persona.

    Architectural anti-patterns avoided¶

    Anti-pattern name Where avoided? Why avoided?
    GOD MODULE Across the overall package structure Prevents combining routing, formatting, and compiling in one unmaintainable prompt.
    ALL-BRANCHES-LOADED In latex-workflow Prevents inflating prompt tokens with rules for all skills when only one is required.
    FAN-OUT-IN-ONE-CONTEXT In compile-pdf Prevents flooding the parent conversation with tokens of verbose compiler log noise.
    EAGER BLOAT In latex-table-formatter Prevents inlining large LaTeX template blocks directly inside SKILL.md bodies.
    STUB ORCHESTRATION In latex-workflow Avoids a pass-through wrapper by introducing interlock, gate, synthesis and doesn't block direct skill invocations.
    TOOLLESS ASSERTION In latex-compiler Prevents hallucinating build status without actually executing the compiler CLI.
    WRAPPING WITHOUT BLOCKING In latex-compiler diagnostics Halts downstream tasks immediately upon build errors instead of proceeding silently.

    Setting up the package repository¶

    Initialize the package repository¶

    Following the APM workflow established in the basic setup and installation walkthrough, create a directory named latex-skills:

    mkdir latex-skills && cd latex-skills

    Initialize it with APM:

    apm init

    Declare external dependencies¶

    The canonical package does not rebuild Mermaid rendering or rephrasing logic from scratch. It reuses external APM packages and keeps its own package focused on LaTeX orchestration and formatting, aligning with the composability principles in the package organization guide:

    apm install KTFish/llm-text-rephrasing-skills#v0.2.0
apm install KTFish/mermaid-skills#v0.2.0

    This yields an apm.yml configuration:

    name: latex-skills
version: 0.1.0
description: Skills for efficient LaTeX document development.
targets:
  - copilot
  - gemini
  - antigravity
  - claude
dependencies:
  apm:
    - KTFish/llm-text-rephrasing-skills#v0.2.0
    - KTFish/mermaid-skills#v0.2.0
  mcp: []
includes: auto

    The package name and the exposed skill name can differ: KTFish/llm-text-rephrasing-skills exposes the skill named llm-text-rephrasing, while mermaid-skills contributes both draw-mermaid and export-mermaid.

    Primitive relation: external packages

    External dependencies like KTFish/mermaid-skills and KTFish/llm-text-rephrasing-skills illustrate the external package relation type. Rather than duplicating diagram rendering or tone auditing in latex-skills, the package imports them as pinned upstream dependencies.

    Configure execution targets¶

    As discussed in the package organization guide, the targets field determines where APM integrates primitives across different agent harnesses. 1

    targets:
  - copilot
  - gemini
  - antigravity
  - claude

    Running apm install then deploys primitives into target-specific locations, such as .agents/skills/ for Antigravity and .github/skills/ for Copilot.

    We recommend starting with a single target (e.g. the harness you use most frequently) to avoid confusion. More targets can always be added later.

    Host dependencies¶

    In case of installation issues

    In case of installation issues skip this step, as it is not the most important step to understand the core concepts relevant for the workshops. Installation of system level dependencies (latex, mermaid) can be finished latter on.

    Mermaid CLI¶

    Install Mermaid CLI to compile and render Mermaid diagrams, especially .mmd files converted to .pdf or .svg:

    Mac / Linux: 

    brew install mermaid-cli

    Windows: 

    npm install -g @mermaid-js/mermaid-cli

    LaTeX compilation (LuaLaTeX + latexmk)¶

    Mac: 

    brew install --cask mactex

    Linux: 

    sudo apt-get install texlive-full latexmk

    Windows: 

    winget install MiKTeX.MiKTeX
