HackathonHub

Copy link

HackathonHub is a great platform if you are actively seeking for hackathons to participate in. It aggregates challenges from Europe in a single place. Allows filtering and setting alerts for specified requirements. The founders position themselves as an alternative to Devpost, which “has 5x less hackathons taking part in Europe”.

Zen: the successor of Arc

Copy link

A modern open source web browser, Arc inspired, with spaces and vertical tabs. You can use your preferred search engine inside (Google, Bing, DuckDuckGo, Ecosia and others).

Pros

  • +Arc inspired
  • +Open source
  • +Vertical tabs
  • +Spaces
  • +Easy migration from Arc
